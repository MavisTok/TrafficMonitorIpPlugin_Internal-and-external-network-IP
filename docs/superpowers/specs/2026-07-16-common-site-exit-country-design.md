# 常见网站出口国家检测设计

## 目标

在 TrafficMonitor 插件的悬浮提示最下方新增“出口检测”段落，分别展示 Google、YouTube、OpenAI、Claude、GitHub、Netflix 经当前系统代理和分流规则访问时，由目标网站可靠识别出的出口国家/地区。

功能由独立设置开关控制，默认关闭。用户启用后写入现有 `tm_ip_plugin.ini`，重启 TrafficMonitor 后保持设置。

## 展示格式

固定按以下顺序展示：

```text
──────── 出口检测 ────────
Google   → 🇭🇰 Hong Kong
YouTube  → 🇯🇵 Japan
OpenAI   → 🇺🇸 United States
Claude   → 🇸🇬 Singapore
GitHub   → ❔ Unknown
Netflix  → 🇯🇵 Japan
```

- 仅展示国家/地区，不展示出口 IP、城市或 CDN 机房。
- 服务名补齐到 7 个 ASCII 字符，使箭头和结果处于同一文本列；最终在 PluginTester 的原生 Tooltip 中检查视觉效果。
- 国家/地区名称使用英文，ISO 3166-1 alpha-2 代码用于生成 Unicode 国旗。
- Windows 不支持对应国旗字形时，允许系统自然降级为区域字母。
- 首次检测尚未完成时显示 `⏳ Detecting...`；单站没有可信结果时显示 `❔ Unknown`。
- 该段落始终位于悬浮提示最下方，与现有 Claude 风险段落的开关和内容相互独立。

## 方案选择

采用“网站原生地区信号”方案。插件分别访问真实站点域名，使请求命中用户为各站配置的分流规则；仅在目标站响应提供可信国家信息时展示结果。

不采用以下方案：

- Clash/Mihomo 控制接口：仅兼容特定代理客户端，需要额外的控制端口和密钥配置，并且代理节点所在国不一定是最终出口国。
- 重复访问同一个 IP 查询服务：所有请求通常命中该查询服务自身的分流规则，不能代表六个目标网站的独立出口。

## 模块边界

新增独立的 `exit_detection` 模块：

- 定义固定站点列表、单站状态和只读快照。
- 发起后台检测并维护 10 分钟缓存。
- 实现每个站点的响应解析器。
- 校验 ISO 国家代码、生成旗帜并取得英文国家/地区名称。
- 生成可直接附加到 Tooltip 的对齐文本。

插件主类负责：

- 根据设置与现有刷新事件请求检测。
- 读取快照并把出口检测段落追加到 `tooltip_`。
- 加载和保存 `enable_exit_detection` 设置。

设置对话框负责独立开关，不把出口检测绑定到 `enable_claude_risk_check`。

## 探测来源

每个站点使用独立探测器：

- Google：访问 Google 自有的客户端映射响应，提取 Google 所见出口 IP，再以该显式 IP 查询国家。后续国家查询的网络路由不会改变被查询的 IP。
- YouTube：访问 YouTube Premium 页面，解析页面明确返回的 `countryCode`。
- OpenAI：访问 OpenAI/ChatGPT 域名提供的 Cloudflare trace，解析 `loc`。
- Claude：访问 Claude 域名提供的 Cloudflare trace，解析 `loc`。该探测与现有 Claude 风险模块分离，两个设置互不依赖。
- Netflix：访问无需登录的公开内容页，解析页面中的国家/地区代码。
- GitHub：访问 GitHub 并由独立解析器检查可信国家字段。GitHub 当前没有稳定公开的客户端国家字段时返回 `Unknown`，不能用 GitHub 服务端或 CDN 机房位置冒充用户出口。

站点页面和未文档化字段可能变化，因此解析器彼此隔离；某一站失效不影响其他站点，也便于单独更新。

## 刷新与并发

- 开关从关闭变为开启后立即安排一次后台检测。
- 正常缓存有效期为 10 分钟。
- 代理软件窗口事件或右键“刷新外网IP”会强制安排一次检测。
- 同一时间最多运行一个出口检测后台任务；已有任务运行时合并重复请求。
- 刷新期间保留上一份成功快照，不把已有结果短暂清空。
- 首次检测时快照标记为检测中；整个批次完成后一次性发布新快照。
- 关闭功能时停止安排新任务，已启动的短任务允许自然结束，但 Tooltip 不再读取或展示结果。
- 后台线程不捕获插件对象地址，只操作模块内部受互斥锁保护的状态，避免插件生命周期问题。

## 网络与容错

- 沿用项目现有 WinHTTP 和当前用户系统/IE 代理解析方式，确保请求经过用户现有代理配置。
- 每站使用有限的连接、发送、接收超时，并限制最大响应体大小。
- HTTP 失败、超时、空响应、响应过大、字段缺失或格式非法均只影响当前站点。
- 解析结果必须是两个 ASCII 字母；统一转换为大写后才进入快照。
- 国家名称无法映射时仍可显示国旗和两位代码，不能把未知代码解释为其他国家。

## 配置

在 `PluginOptions` 中增加：

```cpp
bool enable_exit_detection = false;
```

在 INI 的 `[ip]` 段保存：

```ini
enable_exit_detection=0
```

设置对话框新增“启用常见网站出口检测”复选框。修改后沿用现有选项保存流程，因此只需配置一次。

## 测试与验收

按照测试驱动方式覆盖：

- Google 客户端映射响应中的出口 IP 解析。
- YouTube `countryCode` 解析。
- Cloudflare trace `loc` 解析。
- Netflix 地区代码解析。
- GitHub 缺少可信国家字段时返回未知。
- 空响应、畸形字段、小写代码、非两位代码和非 ASCII 代码。
- ISO 代码到国旗与英文国家名的转换及未知代码回退。
- 六行固定顺序、服务名补齐、检测中和未知状态的 Tooltip 格式。
- 10 分钟缓存、并发请求合并和强制刷新状态转换。

完成后执行：

- Debug x64 构建。
- Release x64 构建。
- 解析和格式化测试。
- PluginTester 人工检查 Tooltip 的段落位置、换行、国旗降级表现和列对齐。
